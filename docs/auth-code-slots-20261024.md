# 校友申请邮箱验证码

邮箱验证步骤改用核心 `DOtp @variant="animated"`，与登录及邀请注册采用相同的主题配色、数字落入、拒绝清空和成功反馈。通过 FormKit 自定义字段保留表单提交、错误说明与无障碍语义。验证请求期间锁定输入和相关操作；验证码无效时清空后保留说明，网络及服务异常保留输入供重试。

此修改依赖主站新增的 `discourse/lib/otp-feedback` 和动画验证码。配套核心版本为 [211f043](https://github.com/ISBF-Lab/ISBFweb/commit/211f043f51681951bbb6d562ca9df66ea73366c6)，生产须与该版本一起增量发布；不得单独安装本插件后重启旧核心。集成工作流固定到该提交，并运行邮箱验证及既有邀请密码测试。

独立开发环境的校友组件验证为18个用例、74条断言通过，包含本次新增的4个邮箱验证用例。与核心合计75个用例、356条断言通过，另有22项页面/邮箱检查通过。注册步骤及异常反馈使用本地响应夹具，真实邮箱登录仅使用虚构开发账号及本地邮件收件箱；未向生产注入测试数据。构造时配置加载延迟到 afterRender，避免首次渲染过程修改已读取的 busy 状态。

用户于2026-10-24要求 PR 和生产部署；当前记录为发布候选，实际发布及最终视觉验收另行登记。生产发布前须核对活动主题、完整插件及共享文件，保留其他线上功能。
